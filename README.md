## Sobre o projeto

Este projeto foi desenvolvido como parte do meu portfólio enquanto estudo Análise e Desenvolvimento de Sistemas.  
O objetivo é apresentar uma solução simples de gerenciamento comercial focada no agronegócio.

## Tecnologias utilizadas

- HTML
- CSS
- JavaScript

## Funcionalidades

- Interface limpa e responsiva
- Organização de informações comerciais
- Layout voltado para o setor rural
